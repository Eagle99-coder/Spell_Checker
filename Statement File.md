#Statement File

#Problem statement:

-People often make grammatical and spelling mistakes in writing and therefore we need a software to correct mistakes and give available suggestions to the user. 

#Scope of the project:

-Error Detection.

-Correction suggestions.

-Exit the program anytime.

#Target users:

-Students who are learning python programming.

-Who are facing difficulty in reading dictionaries.

-Users who want their word or sentence to be rectified instantly.

#High-level features:

-Spell Detection : identifies incorrect words in user input.

-Automatic Correction : gives suggestion and automatically corrects it.

-Exit option : allows users to exit the program whenever requird.
