# Spell Checker App

#Overview of the project:

-A spell checker app is a software application that checks the spelling of words in a given text.For programming languages, it spell-checks text in comments, and when editing plain text files, the entire file is spell-checked.

#Features:
-It can detect errors and rectifies the word.

-Interactive console interface.

-Exit option is also given to close the program.

#Technologies/tools used:
-Python 3.14.

-pyspellchecker package in python.

#Installation:
-First you need to download and install the latest version of python.

-Then in python you should have a module named spellchecker.

-To install the module type - pip install pyspellchecker.

-Then run the program

#Instructions for testing:
-You can type any incorrect or misspelled word in the terminal when the code is running and press enter to get the result (which is the correct word).

-To exit the program just type 'exit'.
